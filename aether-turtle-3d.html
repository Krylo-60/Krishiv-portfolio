📖 Command Index
turtle.forward()
Move the turtle 1 block forward in the current direction.
turtle.back()
Move the turtle 1 block backward.
turtle.left() / .right()
Rotate the turtle 90 degrees left or right.
turtle.up() / .down()
Elevate or lower the turtle 1 block.
turtle.place([color])
Deploy a block beneath the turtle. You can pass a color.
turtle.dig()
Deconstruct the block directly in front of the turtle.
turtle.inspect()
Scan block in front. Returns color name or null if empty.
turtle.log(msg)
Log a system print out to the terminal panel.
